# VEED API · Learning & development

A one-page demo of VEED's API for training content: presenter videos from a photo and a script (Fabric 1.0),
dubbing, captions, reframing to vertical, clean audio, and script updates with Lipsync 2.0.
Open `index.html` locally, or see the GitHub Pages site. No build step.

- `assets/data.js`: the page content (text and media paths)
- `assets/render.js`, `assets/site.js`, `assets/site.css`: layout and media players
- `inputs/`: presenter images and narrated scripts
- `outputs/learning/`: the generated videos

Exported from the main demo site with `tools/export_learning.py`.
